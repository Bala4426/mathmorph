# Synthetic equation-picture corpus

Generated by `scripts/make_corpus.py` (raw XML + zipfile, no python-docx). Regenerate with:

    .venv\Scripts\python.exe -I scripts\make_corpus.py --validate

`--validate` parses every XML part and converts each file to PDF with LibreOffice headless
(output in `out/corpus_tmp/pdf`).

| File | Covers |
|---|---|
| 01_inline_display | display equations alone in a paragraph, inline equations mid-sentence (PNG + JPEG) |
| 02_table_cells | equations alone in table cells next to "(n)" number cells |
| 03_anchored | three `wp:anchor` equation pictures (excluded) + one inline candidate |
| 04_altcontent | `mc:AlternateContent` picture (Choice DrawingML / Fallback VML); text box (wps Choice / VML Fallback) holding an inline equation |
| 05_vml_legacy | inline VML `w:pict/v:shape/v:imagedata`; one `position:absolute` VML shape |
| 06_ole_equations | `w:object` Equation.3 OLE objects, PNG previews and one WMF preview |
| 07_emf_wmf | inline DrawingML EMF and WMF blips (minimal valid metafiles) + one PNG |
| 08_native_only | native OMML only (`m:oMathPara` / `m:oMath`), no pictures |
| 09_no_equations | text and a table only |
| 10_logo_figure | header logo, footer picture, small colorful body logo, tall (>1in) figure, one equation |
| 11_tracked_comments | `w:ins`/`w:del`, comments around equation paragraphs, equation inside `w:ins` |
| 12_mixed_many | 21 equation pictures (body, inline, table), one rId used twice, one media part under two rIds, one native `m:oMath` |

## expected.json

- `truth_latex`: the exact matplotlib mathtext source used to render the picture, **without** the
  surrounding `$...$`; `null` for logos/figures/metafiles.
- `para_index`: 0-based index of the containing `w:p` among all `w:p` of that part, document
  (pre-)order, counting table, text-box, `mc:Choice` and `mc:Fallback` paragraphs.
- `native_omath` counts all `m:oMath` elements in document.xml (including those inside
  `m:oMathPara`); `native_omathpara` counts `m:oMathPara`.
- `kind`: `inline` (wp:inline), `anchor` (wp:anchor), `vml` (w:pict v:shape, inline or absolute),
  `ole` (w:object preview).
- Categories come from one rule function (`classify` in the generator); first applicable wins:
  container (header/footer) > mc:Fallback > anchored/floating > EMF/WMF > height > 1in > logo-like >
  OLE_PREVIEW > CANDIDATE.
- Equation pictures are rendered at 200 dpi; `wp:extent` is the physical size (px / 200 in), all < 1in.
- OLE `.bin` payloads are placeholder bytes (OLE2 signature + padding), not real Equation.3 data.
